# Webpage to Markdown v3.0.1

🚀 **一键将网页正文转换为干净的 Markdown 文件。**

这是一个基于浏览器用户脚本的网页转 Markdown 工具，适用于文章页、博客页、新闻页、技术文档页等内容型页面。它会优先提取正文内容，并保留常见结构，如标题、列表、表格、代码块、引用、图片和数学公式。

## 📦 安装方式

1. 安装浏览器扩展：**Tampermonkey**（推荐）或 **Violentmonkey**。
2. 打开脚本管理器，创建一个新脚本。
3. 将 [Webpage to Markdown.js](Webpage%20to%20Markdown.js) 中的全部内容复制进去。
4. 保存脚本并刷新需要转换的页面。

## 🛠️ 使用方法

1. 打开任意文章或博客页面。
2. 点击浏览器工具栏中的脚本管理器图标。
3. 选择 **"🔄 Convert Page to Markdown"**。
4. 脚本会自动识别正文并生成 Markdown 文件。
5. 文件默认会下载为 `标题_日期.md` 的格式。

## ⚠️ 使用限制

这个脚本适合多数“静态内容页面”，但并不是万能转换器，以下情况可能不稳定：

- 需要登录后才展示正文的页面
- 由大量 JavaScript 动态渲染的页面
- 抗爬虫、反脚本或页面内容被分段懒加载的站点
- 含有复杂广告、推荐位、弹窗、交互式组件的页面
- 表单页、商店页、论坛页、富交互应用页

在这些情况下，脚本可能会：

- 抽取到额外导航/广告内容
- 丢失部分正文结构
- 无法正确提取图片或代码块
- 生成内容过短或过长

如果页面有明显的“正文之外内容”过多，建议先手动确认提取结果后再保存。

## 📱 兼容性说明

### 浏览器支持

- Chrome / Edge：推荐，兼容性最好

### 用户脚本管理器支持

- Tampermonkey：推荐，支持度最好

### 页面环境要求

- 需要页面完成加载后再运行脚本
- 对跨域或 CSP 限制较严的页面，部分外链资源可能不能正常加载
- 有些站点使用懒加载或图片 CDN，提取结果可能需要二次校验

## ⚙️ Tampermonkey 下载配置

为避免浏览器每次询问下载权限，建议按如下方式配置：

1. 打开 Tampermonkey 管理面板 -> **设置**。
2. 将 "配置模式" 改为 **高级**。
3. 找到 **Downloads BETA** 或等效下载配置项。
4. 在白名单文件扩展名中添加：`.md` 或 `^.*\.md$`。
5. 保存设置并刷新页面。

如果配置失败，脚本也会自动回退到浏览器原生下载，不会完全失效。

## 🔒 安全与隐私说明

- 该脚本只读取当前页面的 DOM 内容，并不会上传内容到第三方服务器。
- 它不会主动执行远程脚本或修改浏览器设置。
- 由于脚本运行在页面上下文中，仍然建议避免在不可信网站上启用脚本。
